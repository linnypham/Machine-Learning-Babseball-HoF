# README

This project is a machine learning model that predicts the Hall of Fame induction of baseball players based on their batting and pitching statistics.
# install
install dependencies from requirements.txt

if first time, run decisionTree.py, logisticRegression.py, randomForest.py to generate models.

# run
run hof_gui.py to use model: (default using logistic regression model, can be changed in hof.py code)

input first and last name of player to predict
